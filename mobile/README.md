# 剧本工坊 · 安卓写作版

版本：0.1.6。Android 10 或更新系统，手机与平板。默认简体中文，界面支持 English / 繁體中文。完全离线，不含账号、服务器、局域网协作或云同步，不申请网络或全盘存储权限。

本软件由1037 Film 郭之然独立开发完成

## 已实现范围

- 本机项目库、自动保存、独立恢复副本、回收站及 SSProj 文件备份。
- 触屏段落编辑、中文输入法保护、撤销重做、段落类型/加粗/斜体/下划线/字体、段落移动和确认删除。
- 好莱坞、东亚、舞台、广播剧四种格式；共享桌面版分页与导出引擎，PDF 与逐页 PNG 导出。
- SSProj、FDX、DOCX、TXT、Fountain 导入，SSProj、FDX、TXT 导出；每个导入文件最多 20 MB。
- 查找替换、角色统计、连续场序、故事结构提示和 10 个原创好莱坞示例。

手机编辑采用适应屏宽的重排模式，不把纸张硬缩到手机上。最终纸张布局以分页预览、PDF、PNG 为准。段落样式支持整段设置，不等于任意局部富文本编辑。

桌面制片数据库、锁页和双栏对白等高级信息在项目中保留，但本版不提供对应的专业生产界面。锁页项目在安卓端只读，正式生产版本请继续在桌面版维护。导入 Word 主要识别正文，复杂表格/文本框/批注以及 Fountain 行内强调和双栏布局不保证复原。教学案例原文为简体中文。

## 第一次使用

安装 APK 后打开「剧本工坊」，直接从场景行开始写。底部选择段落类型，用加号续写；硬件键盘 Enter 换段，Shift+Enter 在段内换行。中文输入法确认候选词不应换段。段落选项可设置样式、移动或删除当前段，删除可撤销。

顶部文件夹进入本地剧本库，可新建、导入或恢复回收站项目。导入始终新建一个项目，不覆盖正在写的稿件。顶部 PDF 图标打开安卓系统打印界面，选择「另存为 PDF」，等待缩略页和页数出现，再点保存图标并选择位置；这不是实体打印，不需要打印机。更多功能内可导出 PNG、SSProj、FDX 和 TXT。PNG 在所选目录中新建独立文件夹，逐页保存。

应用内自动保存不等于外部备份。重要稿件请定期导出 SSProj 到系统文件目录；卸载或清除应用数据会删除本机项目和恢复副本。应用不会上传稿件。

0.1.1 修复内置中文字体共享字形造成的 PDF 复制变字（包括“胶”）。常规和粗体均采用独立 Unicode 字形映射，保留原字符、字形轮廓和字宽，不靠替换正文或提取后纠错。第三方字体仍需单独核对。PDF 用于阅读交付，不代替可编辑的 SSProj 备份。

本版同时修复长段落横竖屏切换后的高度重算、新增段落的焦点保持，正文增加硬件键盘 Ctrl/Command+Z、Shift+Z、Y 和 S。输入法候选词确认时不触发正文快捷键；未变化的重复提交不再产生多余撤销和保存。

0.1.2 进一步把一次中文选词合并为一个撤销事务，取消选词也保留原撤销/重做历史。主存储及恢复副本的临时写入失败会退避重试；恢复优先依据单调版本号，不再仅看系统时间。异常副本不阻止打开有效原稿，有冲突的未保存副本另建恢复项目，不覆盖库中的版本。导出取消明确提示；批量替换在分配膨胀文本前检查限额。

0.1.3 修复慢速保存期间撤销回旧稿后，旧的落盘任务覆盖撤销结果的问题；保存确认按每次编辑的递增序号判断，同一时刻只运行一个主存储保存任务。切后台立即独立写入恢复副本，不等待可能挂起的主存储，同时监听安卓原生暂停/恢复信号。长篇中新增、删除、撤销和重做保持附近段落选区；导出前收尾输入法的最终提交，导出完成、取消或失败后可继续输入。后台抢救不等于已确认的完整保存；系统立即强杀或断电仍可能中断写入，请保留外部 SSProj 备份。

后续更新使用相同应用标识和本地保管的签名证书，直接覆盖安装。不要先卸载。若系统提示签名不一致，停止安装并反馈，不要通过卸载来绕过。

0.1.4 进一步保护交错操作：切换时迟到的输入法提交先保存回原项目，再显示目标项目；重新打开当前项目不安装旧列表快照，跨项目重置输入合并历史。本机数据库打开及事务设有响应超时，超时释放操作，迟到的打开结果不会继续写旧稿。写入已完成但回调缺失时，重试先逐字段核对自己的尝试记录；真正的外部修改仍按冲突保护，不直接覆盖。反复切后台、切项目和连续导出仍建议保留独立 SSProj 备份。

0.1.5 加固锁屏、进程终止和空间不足时的恢复。锁屏前抓取当前编辑框最后可见文字；恢复副本使用独立串行写入通道，显式同步、检查原子替换结果并完整回读。写入失败保留上一份完整文件，不显示保存成功。恢复写入失败保留原项目身份或冲突副本名称，不重新生成匿名项目，不复活已删除稿件；本地项目尚未读完时暂停编辑和自动写入，提供“重试读取”和项目导出。测试覆盖真实模拟器熄屏、外部强制终止进程以及内核 ENOSPC 写入错误；这不等于所有厂商的锁屏或低内存回收行为。若空间完全耗尽且两个存储均写入失败，当前未落盘文字仍可能在强杀或断电时丢失，请勿在提示失败后退出，优先释放空间或导出 SSProj。

0.1.6 修复恢复冲突检查可能放宽旧编辑器覆盖权限的问题：读取不会改变写入基准，仅本写入器已确认的提交可以推进较旧的在途快照。启动复核读到较新原稿时使用该正文；旧一轮恢复失败不再残留到已保存的新稿提示。新增保存失败后持续输入、撤销重做、切项目及恢复冲突交错测试，包含原生输入连接和真实本地存储；原稿与冲突副本分别保留。空间未恢复时仍不可把内存中的文字当作已落盘，重要稿件请另存 SSProj。

导入项目保留原段落标识；带引号等特殊字符的标识会安全转义，不再导致撤销/重做的焦点恢复抛出选择器错误。

## 开发与验收

在仓库根目录运行 `npm ci`，再于本目录运行 `npm ci`、`npm run build` 和 `npm run sync`。原生工程需要 JDK 21、Android SDK 36。原生 CI 构建安装包，并在 Android 10 / Android 16 模拟器验证旧版覆盖升级、本地桥接、导入、保存、恢复、PDF 和 PNG。系统文件选择结果在仪器测试中以本机 URI 注入；PNG 使用仅存在于 debug 工程的受系统权限保护的 DocumentsProvider。它们不能代替每个厂商文件管理器的真机体验测试。

字体维护使用 Python/fontTools 4.67.0，`scripts/prepare-cjk-fonts.py --verify` 校验内置字形的全部 Unicode 覆盖、advance 和别名轮廓；`make-unicode-probe.py` 生成常规/粗体复制测试项目，`verify-pdf-copy.py` 对实际 PDF 逐字核对。

公开包由开发机持久保存的私钥签名；签名私钥和口令不进入源代码、构建日志或 CI。浏览器适配测试不能替代原生 Android 验收。
